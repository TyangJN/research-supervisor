# 证据、实验与研究决定

## 证据与主张

影响结论的来源要记录支持什么、不支持什么。拿到全文或数据不意味着可支持任何主张，仍需定位相关方法、结果与条件。

| 材料 | 可支持 | 需要进一步证据 |
|---|---|---|
| 标题、作者、年份、DOI 等元数据 | 身份；标题明确表达的主题 | 技术细节、数字、比较、未陈述的限制 |
| 摘要 | 摘要明确报告的发现，注明依据摘要 | 未报告的细节、归因、泛化和局限；数字需保留条件 |
| 全文及补充材料 | 对应具体段落/图表的报告内容 | 独立复现成功、未经检验的因果解释 |
| 结果表或运行产物 | 已知协议和分析范围内的观察 | 缺少比较条件时的优越性；无控制时的机制证明 |
| 用户口述 | 用户报告且待核对产物的观察 | 将未核对材料称为已复现，或将猜测当事实 |
| 计划、机制论证、模型生成想法 | 假设、拟检验关系、预期 | 已经观察到的结果或虚构数字 |

记录版本/日期和可定位位置；关键新颖性、比较和结果主张可追溯，普通背景无需繁重账本。检索围绕当前决定，兼顾支持、反对与相邻解释，不追求固定篇数。

分别核验“来源存在”和“支持这句话”。检索失败、限流、全文不可得与正常搜索无结果是不同状态。无法核验的条目作为待办或移出最终引用，不伪造补齐。重要主张需对应正文/方法/结果，不能靠相似标题推断。

## 从解释到可区分预测

对观察提出候选机制，同时保留合理替代解释。说明什么比较会使它们预测不同结果；若各解释预测相同，该实验通常不能完成归因。

计划至少说明与本轮有关的内容：

| 项 | 作用 |
|---|---|
| 问题与假设 | 减少哪项不确定性 |
| 比较与控制 | 改变、保持、排除什么 |
| 单位与数据 | 独立单位是什么，样本来自哪里 |
| 观测量与分析 | 指标意义，必要分层、成本或误差分析 |
| 预期与反证 | 什么支持、削弱或不能区分解释 |
| 预算与停止 | 实际估算的时间、计算、标注成本及继续条件 |

计划数字明确标为预算、目标或设计选择。用小实验取得噪声和可行性信息，再决定是否扩大，不把探索试点宣传为正式效应验证。

## 落后或没有提升时

按可能改变结论的顺序诊断，不机械穷举：

1. **实现与测量**：解析、标签、指标方向、收敛、数据加载、统计单位是否正确？
2. **公平性**：数据、输入信息、基础模型、计算和调参机会是否可比？不匹配如何影响所声称的结论？
3. **不确定性**：重复/配对比较、误差范围、效应大小与样本结构是否足够区分噪声？
4. **机制**：干预真的改变了目标因素吗，测量能看到预测吗，有哪些替代解释？
5. **决定**：修实现、补有信息量的对照、收窄结论、改假设或停止。

不显著不等于无效应；等效/非劣性需合适设计和界值。低于 baseline 不自动否定研究价值，可靠负结果可以纠正认识。也不能无限调参挽救已被可信证据否定的预测：对照和测量充分、重复证据相符、关键预测持续失败时，明确建议修订或放弃该主张。

## 获得提升时

先检查泄漏、额外信息、计算预算、预处理、基础模型与样本选择能否解释收益。实用效果比较与机制归因可能需要不同实验；不强求每个改进都证明完整因果机制，但不能声称未经验证的原因。

## 统计与评估边界

- 分析单位依据设计决定；同一对象的多个问题、时间窗、重复推理或折数不自动独立。按问题选择配对、聚类、层级或其他合适分析。
- 报告适用的效应与不确定性；检验、区间与重复运行应回答明确问题且假设可支持，不强制每种材料都算 p 值或固定次数。
- 声明比较范围，区分预先指定与探索发现；多重比较按推断目的处理。不只挑最佳运行、显著子集或有利指标。
- 看测试结果后调参、选模型或改样本都会改变独立性。保留接触记录，用未参与选择的数据确认，或明确结果仅属探索。
- 检查与项目有关的数据使用条件、标注质量和任务真实性，不默认增加无关的审批清单。

## 内层执行，外层反思

内层完成有预算的“假设—方案—运行—检查—记录”。外层在有解释力的新证据、连续停滞或预算节点时回看：新增什么认识，排除什么，下一轮还会改变决定吗？可以深化、补证据、转向、收束或暂停。

保留问题、证据、失败经验和决定，避免只累计成绩表。关键问题已有足够答案、增量信息小、预算耗尽或依赖不可得时可以停止，指出恢复需要什么。不要自动设定时任务或要求永不停止。
