# 研究记录

按项目需要使用相关部分，不必一次填满。ID 在项目内稳定且唯一；日期为实际记录日期。

## 当前问题

- 问题 ID / 路线 / 阶段：
- 对象、任务与用途：
- 当前想法与最接近的已有工作：
- 为什么值得研究：
- 用户决定与范围边界：
- 已有证据 / 仍缺证据：
- 什么支持 / 削弱 / 不能区分当前解释：
- 最小下一步、预算与停止条件：

## 证据条目

- 证据 ID / 来源及位置 / 日期与版本：
- 类型：全文 / 摘要 / 元数据 / 实验产物 / 用户报告 / 计划：
- 观察与条件：
- 支持什么 / 反对什么 / 不能支持什么：
- 不确定性与待核验项：
- 允许的结论 / 尚不允许的更强结论：

## 实验条目

- 实验 ID / 问题 ID / 探索或确认 / 计划日期：
- 假设与替代解释：
- 比较、控制、数据与分析单位：
- 观测量、分析、预期和反证：
- 预算、继续与停止条件：
- 代码/数据/模型/环境版本、日志和原始结果位置：
- 计划变更及发生时间：
- 实际观察（未运行则明确写未运行）：
- 解释、限制与决定：
